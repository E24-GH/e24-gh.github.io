FIRMWARE & SETUP GUIDE

ZEN の設定

ファームウェアを書き込んで、ブラウザからキー配置とトラックボールを設定するまでの手順です。

A コンボ／マクロを使わない方 はじめて設定する方もこちらです。GitHub の操作は必要ありません。
0 → 1 → 2 の順に進めてください。 B コンボ／マクロを設定している方、またはこれから設定する方 コンボとマクロは設定ファイルを編集するため、GitHub を使います。
0 → 3 に進んでください。

すでに ZEN をお使いの方は、4 すでにお使いの方へ もあわせてご覧ください。

00 — REQUIREMENTS

必要なもの

  • ZEN 本体
  • 対応コントローラ（左右）
  • データ通信対応の USB Type-C ケーブル
  • Mac / PC と、Chrome または Edge
ブラウザについて
設定画面はキーボードと USB で直接やりとりします。Chrome または Edge をおすすめします。
Safari では動きません。iPhone / iPad は、どのブラウザアプリを使っても対応していません。Android は Chrome 148 以降で動作します。
01 — FLASH

ファームウェアを書き込む

左右それぞれに、お使いの構成に合うファームウェアを書き込みます。まず zip をダウンロードしてください。

ファームウェアをダウンロード

右手側 — お使いの構成に合うものを1つ

  • zen_right_trackball_pmw3610_central-bmp_boost-zmk.uf2PMW3610（標準）
  • zen_right_trackball_paw3222_central-bmp_boost-zmk.uf2PAW3222
  • zen_right_trackpad_central-bmp_boost-zmk.uf2トラックパッド

左手側 — 構成に合うものを1つ

  • zen_left_peripheral-bmp_boost-zmk.uf2トラックパッドなし（標準）
  • zen_left_trackpad_peripheral-bmp_boost-zmk.uf2トラックパッドあり

標準構成なら、右手は PMW3610 用、左手はトラックパッドなし用の2つです。

書き込み手順

  1. 右手側の対応コントローラを、電源スイッチを OFF にした状態で、USB ケーブルで Mac / PC と接続します。これでブートローダーモードになります。電源スイッチは、向かって奥側が OFF の状態です。
  2. BLEMICROPRO というフォルダが表示されるので、これを開きます。表示されない場合は、USB ケーブルがデータ通信に対応しているか確認してください。
  3. 解凍した zip の中から、右手側の UF2 ファイルを BLEMICROPRO フォルダにコピーして書き込みます。書き込み後、ドライブの取り外しに関する通知が表示される場合がありますが、書き込みは正常に完了しています。
  4. 続いて左手側の対応コントローラを、同じ手順でブートローダーモードにします。
  5. 左手側の UF2 ファイルを BLEMICROPRO フォルダにコピーして書き込みます。
02 — CONFIGURE

Configurator で設定する

キー配置、トラックボールの速さ、無線の接続先を、ブラウザから設定できます。

ZEN Configurator を開く
  1. 右手側を USB ケーブルで Mac / PC につなぎます。左手側はつなぐ必要はありません。
  2. Configurator を開き、右上の キーボードをつなぐ を押します。
  3. ポートを選ぶ画面が出たら ZEN を選んで接続します。2回目以降は、この画面は出ずにそのままつながります。
  4. つながると、いまキーボードに入っている設定が読み込まれます。

できること

  • キー — キー配置の変更。レイヤーごとに編集できます
  • マウス — トラックボールの速さ、スクロール、向き、オートマウス
  • BT — 無線の接続先の切り替えと削除
  • カラー — 画面のキーボードの見た目を変えて遊べます。キーボードには何も送りません。配色を試したり、お手元の ZEN に似せたりする、画面の中だけの機能です。
変更は「キーボードに保存」を押すまで残りません
画面下に、この画面 → キーボードで試す → キーボードに保存 の3段階が表示されます。保存を押さずに電源を切ると、変更は元に戻ります。
03 — COMBOS & MACROS
ROUTE B

コンボ／マクロを使う

コンボ（2つのキーの同時押しを別のキーとして使う機能）とマクロは、キー配置と違ってキーボードに直接送ることができません。ファームウェアに焼き込まれているためです。使いたい場合は、設定ファイルを書き換えてファームウェアを作り直します。

ここからは GitHub を使います。コンボもマクロも使わない場合は、このセクションは読み飛ばしてください。

  1. E24-GH/zen-keyboard を開き、右上の Fork から自分のアカウントにコピーを作ります。
  2. すでに ZEN をお使いで、以前の fork に設定が入っている方は、先に「すでに ZEN をお使いの方へ」の手順で config/keymap.keymap を移してください。はじめての方は、この手順は不要です。
  3. fork した自分のリポジトリで config/keymap.keymap を開き、Raw からファイルをダウンロードします。
  4. Configurator の コンボ タブで、そのファイルを読み込みます。
  5. コンボを追加・編集します。同時押しするキーは、画面上のキーボードをクリックして選べます。
  6. keymap.keymap をダウンロード を押します。
  7. GitHub に戻り、config/keymap.keymap の内容をダウンロードしたファイルの内容で置き換えて commit します。
  8. Actions タブで build の完了を待ち、firmware の zip をダウンロードします。
  9. 「ファームウェアを書き込む」と同じ手順で書き込みます。
マクロについて
Configurator の コンボ タブが編集できるのはコンボだけです。マクロは config/keymap.keymap を GitHub 上で直接編集してください。書き込むまでの流れ（commit → Actions → 書き込み）は上と同じです。
キー配置は Configurator、コンボ／マクロは設定ファイル
この2つは別々に保存されます。同じキーを両方で変更すると、Configurator で設定した内容が優先されます。設定ファイル側の変更を反映させたいときは、先に Configurator の プリセット →「出荷時の設定に戻す」を実行してください。
04 — ALREADY USING ZEN

すでに ZEN をお使いの方へ

以前のファームウェアは Configurator に対応していません。切り替えるとブラウザから設定できるようになります。

ルート A の方（コンボ／マクロを使わない）

「ファームウェアを書き込む」の手順でそのまま書き込んでください。無線の接続先とトラックボールの設定はそのまま残ります。

キー配置をカスタマイズしている場合
いま設定されているキー配置は、いったん標準に戻ります。「Configurator で設定する」で付け直す形になります。画面でキーを選ぶだけなので、たいていは数分で終わります。
作り込んでいて、そのまま移したい場合は、下のルート B の手順でも移行できます。

ルート B の方（コンボ／マクロを使う）

以前の fork で編集した config/keymap.keymap を、新しいリポジトリに移します。キー配置もコンボもマクロも同じファイルに入っているので、ファイルごと移せばそのまま引き継がれます。

  1. E24-GH/zen-keyboard を fork します。
  2. 以前の fork（zen-firmware）で config/keymap.keymap を開き、Raw の内容をすべてコピーします。
  3. 新しい fork の config/keymap.keymap を編集し、すべて貼り替えて commit します。
  4. Actions タブで build を待ち、firmware の zip をダウンロードして書き込みます。
keymap.keymap 以外も変更している場合
スリープ時間など boards/shields/zen/ 以下の設定も変更している場合は、その差分もあわせてご確認ください。
05 — FAQ

よくある質問

いまのファームウェアのままでも使えますか

使えます。移行は必須ではありません。ただし、これまでキー配置の編集に使っていた Keymap Editor は、提供元が GitHub 連携の終了を予告しています。止まると、いまのファームウェアではキー配置を変更する手段がなくなります。

いまの設定は消えますか

無線の登録（ペアリング）とトラックボールの設定は残ります。キー配置とコンボ／マクロは、新しいファームウェアに入っているものに置き換わります。

カスタマイズしている方は、「すでに ZEN をお使いの方へ」の手順をご覧ください。

元のファームウェアに戻せますか

戻せます。ただし Configurator で設定した内容はキーボード本体に残っているため、戻したあともそちらが優先されます。

先に Configurator の「プリセット」→「出荷時の設定に戻す」を実行してください。

iPhone / iPad から設定できますか

できません。設定にはブラウザが USB 機器とやりとりする機能が必要で、iPhone / iPad はどのブラウザアプリを使っても対応していません。Mac / PC の Chrome または Edge をお使いください。

「カラー」タブは何ですか

画面に出ているキーボードの見た目を変えるだけの機能です。キーボードには何も送っていません。配色を考えるときの遊びとしてお使いください。

ZMK Studio は使えますか

配布しているファームウェアでは無効にしています。Configurator と同じ USB の口を取り合うため、両立できません。キー配置の編集は Configurator をお使いください。

どうしても使いたい場合は、ご自分でビルドすれば切り替えられます。そのかわり Configurator は使えなくなります。

切り替える前に
Configurator の「プリセット」→「出荷時の設定に戻す」を実行してください。切り替えたあとは Configurator につなげないため、この操作ができなくなります。
トラックボールの設定は最後に保存した値のまま動きますが、変更する手段がなくなります。
  1. E24-GH/zen-keyboard を fork します。
  2. boards/shields/zen/zen_right.conf を開き、CONFIG_ZMK_STUDIO=n を CONFIG_ZMK_STUDIO=y に変えて commit します。
  3. boards/shields/zen/zen_left.conf も同じように変えます。
  4. Actions タブで build を待ち、firmware の zip をダウンロードします。
  5. 左右に書き込みます。

変更するのはこの2行だけです。これで Configurator 用の仕組みは自動的に外れます。

あとから Configurator を使いたくなった場合は、同じ2行を CONFIG_ZMK_STUDIO=n に戻して、もう一度ビルドして書き込んでください。元の状態に戻ります。

06 — TROUBLESHOOTING

困ったとき

設定を元に戻したい

Configurator の プリセット →「出荷時の設定に戻す」で、この画面から変更したキー配置とマウス操作をキーボードから消せます。ファームウェアに入っている元の設定に戻ります。無線の登録は消えません。

Configurator がキーボードを見つけられない

右手側を USB でつないでいるか確認してください。左手側では設定できません。ブラウザは Chrome または Edge が必要です。

別のタブで Configurator を開いたままだと、そちらが接続を掴んだままになります。使っていないタブは閉じてください。

トラックボールが動かない

キー入力はできるのにトラックボールが動かない場合は、右手側に書き込んだ UF2 がお使いのセンサーに合っているか確認してください。PMW3610 と PAW3222 で別のファイルです。

接続が不安定 / 無線の登録をやり直したい

zip に同梱の settings_reset-bmp_boost-zmk.uf2 を書き込むと、無線の登録を含めてすべて初期化されます。

  1. Mac / PC の接続設定から ZEN を削除します。
  2. settings_reset-bmp_boost-zmk.uf2 を書き込みます。
  3. USB を外します。
  4. ZEN の電源を入れます。
  5. もう一度、通常のファームウェアを書き込みます。
  6. 接続設定から ZEN を再接続します。

Configurator で設定した内容もすべて消えます。先に「出荷時の設定に戻す」で足りないか確認してください。

Actions が動かない

fork したリポジトリの Actions タブを開き、GitHub Actions を有効化してください。

以前の手順を見たい

Keymap Editor を使う以前の手順は こちら に残しています。この手順で使う Keymap Editor は、提供元が GitHub 連携の終了を予告しています。いずれ使えなくなります。
